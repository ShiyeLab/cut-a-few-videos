# 本条视频要求

由 Agent 根据实际材料填写，已明确的要求直接采用；不适用的项省略。

## 目标与输入

- 主题、目标观众、使用场景：
- 希望观众理解或感受到什么：
- 条数、期望片长、输出要求：
- 文案与标题定稿、允许改动的范围：
- 素材目录、事实与引文依据：

## 制作选择

| 事项 | 选择及依据 |
| --- | --- |
| 内容推进 | 开头如何进入、关键内容与转折、结尾留下什么；产品出现怎样与内容对应 |
| 声音 | 复用／新配／无人声；音色、演绎与速度，试听结果或用户委托范围 |
| 时间轴 | 所用完整音频与真实时间轴 |
| 画面 | 已有素材承担什么，实际缺口是什么，如何补足 |
| 视觉方向 | 取景、节奏与贴片风格；可复用的底图和素材 |
| 服务与配置 | 所选主 Agent、理解、生图、视频、配音或检索服务；所需配置是否可用 |
| 调用范围与预算 | 已授权的分析与生成范围、预计需要；仍待用户决定的缺项 |

镜头采用理由写在 `scenes.json`，来源和分析依据写在 `sources.json`，这里不重复抄写。
