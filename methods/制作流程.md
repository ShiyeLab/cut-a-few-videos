# Agent 制作流程

从用户给出的材料出发。Agent 负责判断和执行，使用者提供目标、素材、偏好和需要使用的服务配置。默认主 Agent 为 DeepSeek V4.1 Flash，也可换用其他具备文件、命令与媒体能力的模型。

## 1. 接收并盘点素材

先读用户要求与所有提供材料，填写[素材清单](../templates/video/inventory.md)，同时把明确的目标写入[本条要求](../templates/video/brief.md)。不要把需要 Agent 填写的技术配置转交给用户。

| 材料 | 需要看什么 | 记录什么 |
| --- | --- | --- |
| 文字资料与口播 | 内容事实、用途、是否已有定稿、允许改动范围 | 可用文案、需核对的说法、预期时长 |
| 图片 | 主体、尺寸、清晰度、真实产品与页面 | 数量、可用用途、需避开的裁切 |
| 视频 | 实际动作、连续片段、画面尺寸、是否有原声 | 文件时长、可用源区间、适合哪句口播 |
| 录音与配音 | 内容是否完整、音色、停顿、噪声、末句 | 是否直接复用、有无匹配时间轴 |
| 音乐 | 风格、长度、与人声是否冲突、录音来源 | 可用曲目或待选；是否需要配乐 |
| 海报与设计 | 是否无字、上下能否裁切、风格是否适合 | 可复用底图或新的生图需求 |

图片需要实际看，视频需查看多个时点及拟使用的连续片段，音频需听。素材数量不代表能覆盖口播；长视频也要按实际可用区间计算。原件保留，整理与转码另存。

## 2. 根据材料决定怎么做

把各项选择与理由写入 `brief.md`。用户已明确的要求直接采用；一般制作细节由 Agent 决定。只有确实影响成片的缺项、内容方向、偏好或未授权费用需要集中询问。

| 判断 | 处理 |
| --- | --- |
| 已有完整口播吗 | 有定稿就按要求保留；只有资料则先形成有依据的口播；无旁白需求则走无人声版 |
| 已有可用声音吗 | 内容、听感都合适时复用；需要新声音时选声、短试听，再合成完整口播 |
| 画面是否足够 | 优先真实素材；缺动作可检索或补拍，缺环境可生成；不为了使用 API 而替换足够的实拍 |
| 是否配公版音乐 | 根据情绪、节奏和后期用途判断；可选具体公版录音、用户给的音乐或不配乐；用户未表态且取舍影响风格时给出建议 |
| 贴片怎么做 | 有合适无字底图就复用，否则默认调用生图 API，按内容设计同一张上下贯通的海报 |
| 用哪些服务 | 用户指定的优先，否则采用默认推荐；各环节独立选择，记录所用服务与模型 |
| 能否开始生成 | 核对需要补的素材、生成数量、预算和所需配置；已获授权的操作直接执行 |

公版音乐记录的是具体录音的来源与许可，不能只凭曲作者年代判断录音是否公版。没有可用且来源明确的配乐时，可先出无配乐版本，把音乐选择作为明确待办。

## 3. 准备内容、声音与真实时间轴

图书或产品事实来自用户资料；引用核对原件，不编造内页、页码或使用过程。纯口播保存为 `script.txt`，镜头说明与演绎要求分开。

音色由内容、听众与情绪推进决定，不固定年龄、性别或声线。以完整意思连贯说话，停顿放在语义转换与自然换气处；不逐字发力或切碎词组。代表性短段试听后，再听完整口播。

声音确定后生成 `timeline.json`，每条包含实际开始秒数、结束秒数和文字。有字级时间的服务可直接整理；其他配音或自己录音可通过转写与对齐服务或人工标注取得真实时间，逐句核对。不能按字数平均估时。更换声音、语速或文案后重做时间轴。

无需人声时明确设置 `voice: null` 与片长 `duration`，按画面节奏安排字幕；不要为了满足工具输入而生成无用配音。

## 4. 选镜头与补画面

先把每句口播的意思写成可见动作与场景，再找素材。比如“工作消耗”可对应停下打字、看着文件迟疑；“读到共鸣”可对应手指停在真实书页、读完抬眼。抽象词只用于理解内容，不能代替实际画面核对。

产品封面、内页、翻页和抄写使用对应产品的真实素材。缺少落笔实拍时可展示真实已写页面，不用另一本书或通用笔记本冒充。外部素材补人物动作、情绪与环境。

环境空镜可用默认 MiniMax H3，也可用其他视频 API。提示词写清主体、动作、光线、镜头、时长与禁止内容；环境空镜不得出现文字、书本、手和人物。生成后看抽帧与连续画面，核对物体、运动、禁用内容和可用时长。

把选择写入 `scenes.json` 与 `sources.json`。检查源区间、前后切镜、中央窗裁切和叠化所需的额外尾段。静态图可小幅缓推，必须连续平稳，不抖动、折返或跳位。

## 5. 生成贴片并排字

默认调用 Seedream 5.0 Pro，也可换成其他生图 API。按内容确定色彩、质感与边缘元素，生成一张 9:16 无字海报，取其上下两端做贴片。底图不含文字、印章、logo 或边框，标题与底部文字留给程序排版。

按[海报提示词](../templates/poster-prompt.txt)准备具体提示词，输出本地 PNG/JPG，将路径填入 `project.json` 的 `band_art`。文字使用中文字体、细描边和轻微投影。修改标题只重排文字，换内容或风格才重新设计底图。

## 6. 合成

按[工程说明](../docs/工程说明.md)填写布局、镜头和项目配置，所有素材路径从仓库根目录算起：

```sh
python tools/build_video.py --project projects/my-video/project.json --work projects/my-video/v1
```

工具根据实际声音和片尾留白计算总长，按句首安排镜头，绘制文字并完成中央叠化、混音和合成。既无声音文件也无旁白时，配置中明确填写 `duration`。音乐可不加，人声可不输出，两者都关闭则为全静音。

## 7. 看完整成片并交付

核对每句意思和画面，特别是转折、产品出现与结尾；检查最长字幕、标题和末句；听词组连贯、自然换气、音乐音量和最后一字。保留完整片尾，不通过缩短成片掩盖时间不够的问题。

交付新版本的 `video.mp4`、配置与检查结果，注明实际检查和需用户决定的事项。用户提出修改后，只重做受影响环节；素材、声音、提示词与既有版本可复用。
