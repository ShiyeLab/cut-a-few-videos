# 仓库内容范围

公开仓库名为 `ShiyeLab/cut-a-few-videos`，中文名“剪几个视频”。实际提交只采用[文件清单](publish-files.txt)，当前均为文本文件。

| 内容 | 处理 |
| --- | --- |
| 通用合成、排版、配音、空镜与检索工具 | 保留可复用代码；本地路径与单书配置改为明确参数 |
| 工程说明、制作方法、AI 约定 | 按实际工具编写，提供使用与修改入口 |
| 配置、来源表、演绎与生成提示词 | 提供可填写模板，不含服务回执 |
| 教学例 | 提交生成器和文本配置；图片、视频、声音由使用者离线生成 |
| 两本书的实践 | 只保留方法与必要参数，不附带原书内容或媒体 |
| 字体 | 不上传字体包，使用者另行准备；英文教学例复用 Pillow 默认字体 |
| 原始资料、照片、视频、音乐、配音、生成海报、成片 | 不上传 |
| 真实 Key、环境配置、服务回执、临时地址、缓存与中间文件 | 不上传 |
| 旧系统朗读、早期 ASR、MediaKit 探针和旧占位实验 | 不进入本仓库运行链 |

整理在独立发布副本进行，原制作目录和已有结果保留。新入口从单书制作步骤提取最小配置读取部分；字幕、推近、叠化、混音与排版仍由原有工具实现。

检查记录见[验证说明](validation.md)。新增文件时先判断是否为通用工具或可分发教学输入，再明确更新清单；不要整目录添加个人制作文件。
