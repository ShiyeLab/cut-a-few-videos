# 两本书的制作方法

这里保留选声、选镜和包装的经验。原书文案、照片、视频、音频、海报和成片留在制作目录，不作为仓库示例分发；可运行的输入见[离线教学例](../demo/README.md)。

## 《巴托比》：让画面承接疏离与自我边界

声音方向是清醒、克制、有思考感，能接住孤独和无奈，末句自然转为温和坚定。实际 v4 使用“深夜播客”候选声线，重点通过完整口播判断连贯性，不能因为音色名称合适就省略试听。

画面先把抽象意思落到窗边独处、工作中的停顿、人群各自走过等动作与场景。说出书名时展示真实书封，内页和翻书使用本书素材，结尾回到书封。环境空镜只补充情绪，不承担产品展示。

上下贴片使用灰蓝与米白，让红色书封成为重点；整幅无字海报取上下两端，文字另排。v4 在已有声音和素材基础上加入 MiniMax 环境空镜，成片约 61.67 秒、15 段画面、21 条字幕、10 帧中央叠化。另有无人声与无配乐的本地版本，用于后期配音或检查画面。

## 《偷得浮生半日闲》：先表达被理解，再回到真实手抄本

内容主线是“读书让人发现，自己的感受早已被某个人说清楚”。声音需要亲近、温暖、舒展，中段带一点被理解的释然，结尾温和落下；不照搬另一条片子的厚重与灰蓝色。

配色来自真实封面的浅水青和纸白。真实翻页与内页交替出现，照片采用 2.5%—3.5% 的居中缓推。实际没有落笔实拍时，展示本书已抄写的真实页面，不用普通笔记本或其他书的字迹替代。

已明确采用的基线是 v2：约 63.97 秒、13 段画面、32 条字幕、8 帧中央叠化，沿用首版声音、音乐与配色。v3 尝试把过程段落换成 AI 环境空镜；目录中另有加入生成贴片和更多空镜的 v4，约 63.97 秒、17 段画面。新增文件和机械检查通过不自动改变已确认基线。

## 可以带走的做法

- 音色与色彩服从本条内容，复用布局与工具时重新做创作判断。
- 先有可见动作和场景，再找素材，不能让抽象关键词替代看片。
- 产品内容必须真实，缺少实拍就调整表达，不拿外部素材冒充过程。
- 修改声音后重做时间；修改画面时保留声音，避免无关重生成。
- 末句、片尾与不同声音组合都要单独检查实际文件。

上述参数来自本次整理时对原制作配置、文件信息和检查记录的核对；这里没有附带可一键复刻原片的素材。
